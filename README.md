🧽 Excel Unprotect Tool

把 Excel 的「工作表/活頁簿保護」洗掉的小工具

✋ 冷靜，它不是破解密碼。
🔓 只是幫你移掉「不能按」那一層透明封膜。

🔧 這是什麼？

有些 Excel 不能改，明明不是加密，不是鎖檔，只是「不要你改」。
這個工具可以幫你把：

工作表保護 → 移除

活頁簿保護 → 移除

不需要密碼，資料不會消失，只是「不再被管」。

💡 它能做什麼？
功能	狀態
移除工作表保護	✔
移除活頁簿保護	✔
支援 .xlsx	✔
支援 .xlsm	✔（不會碰你的 VBA）
支援 .xls	✔
加密開啟的 Excel	❌ 不做（不用找我😄）
移除 VBA 密碼	❌ 不做（那是另一個宗教）
🏃‍♂️ 怎麼用？
🖱️ 方式 1：雙擊執行 → 選 Excel → 完成
🎯 方式 2：把 Excel 直接拖進去 → 完成

就這麼簡單。
不需要安裝、不需要外掛、不需要 Office 版本。
